# Project repository

- Canonical repository: https://github.com/avelkoskyeng/tilda.git
- Use `origin` for this repository. The default upstream branch is `origin/main`.
- Push project changes to this repository. Create pull requests here when requested.
- Before preparing a branch or PR, fetch `origin` and check for upstream updates. Integrate updates when needed while preserving local work.
- Keep unrelated local changes out of a task's commits and PRs.
- After changing public helpers or documentation aliases, run `node scripts/check-docs-api.cjs` and `node scripts/check-docs-search.cjs`, plus the checks relevant to the change.
